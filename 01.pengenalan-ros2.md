# `Apa itu ROS2`
Salah satu hal terpenting dalam operasi sebuah robot adalah `pertukaran informasi secara real-time`.

ROS2 (Robot Operating System 2) bertujuan untuk `mempermudah` proses pembuatan dan penjalanan sistem pertukaran informasi tersebut.

ROS2 dapat mempermudah:
- Pengambilan dan penyebaran hasil praproses data sensor ke semua program yang membutuhkan
- Pertukaran informasi antar-program yang berjalan bersamaan
- Pemilihan keputusan tingkat tinggi: kapan saja program apa saja harus bersifat seperti apa saja

> catatan: namanya ROS2 karena dulu ada ROS1. tl:dr; ROS1 udah nggak ada lagi karena ROS2 lebih mudah.

# `Key Takeaway`
Walaupun namanya Robot `Operating System`, Operating System (OS) disini bukan berarti OS seperti Windows atau MacOS.

ROS2 dapat dianggap seperti `framework` yang berada di atas OS masing-masing perangkat yang ingin menggunakannya
