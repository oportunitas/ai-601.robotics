# `Set Locale`
ROS2 perlu berkomunikasi dengan codeset `UTF8`. Ubuntu yang ingin dipakai harus dipastikan dulu menggunakan locale `UTF-8`

> Run untuk set locale menjadi `UTF8`
```
sudo apt update && sudo apt install locales
sudo locale-gen en_US en_US.UTF-8
sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
export LANG=en_US.UTF-8
```

> Run untuk cek apakah locale sudah `UTF8`
```
locale
```

# `Install Ubuntu Universe`
ROS2 perlu aplikasi2 yang ada di dalam Repository `Ubuntu Universe`
> Run untuk menambahkan repository `Ubuntu Universe` agar punya opsi aplikasi yang lebih banyak untuk di-download
```
sudo apt install software-properties-common
sudo add-apt-repository universe
```

# `Simpen link aplikasi ROS2`
> Catatan: sistem APT di Ubuntu adalah di PC kita ada list link2 aplikasi yang bisa didownload. Kalau mau upgrade aplikasinya si APT ini tinggal baca lagi list link2nya terus cek ada nggak yang: udah di install dan di linknya itu appnya versinya udah naik

> Run untuk menambahkan link Repository ROS2 ke list apt-source.
```
sudo apt update && sudo apt install curl -y
export ROS_APT_SOURCE_VERSION=$(curl -s https://api.github.com/repos/ros-infrastructure/ros-apt-source/releases/latest | grep -F "tag_name" | awk -F\" '{print $4}')
curl -L -o /tmp/ros2-apt-source.deb "https://github.com/ros-infrastructure/ros-apt-source/releases/download/${ROS_APT_SOURCE_VERSION}/ros2-apt-source_${ROS_APT_SOURCE_VERSION}.$(. /etc/os-release && echo ${UBUNTU_CODENAME:-${VERSION_CODENAME}})_all.deb"
sudo dpkg -i /tmp/ros2-apt-source.deb
```

> Run untuk update list link2 aplikasi di APT dan cek apakah ada yang keinstall dan perlu di upgrade
```
sudo apt update
sudo apt upgrade
```

# `Install ROS2`
> Run untuk install ROS2
```
sudo apt install ros-humble-desktop
```

> Atau run ini untuk install barebonesnya saja
```
sudo apt install ros-humble-ros-base
```

# `Verifikasi Instalasi`
Sekarang kita coba run sesi ROS2 simpel: buka 2 terminal.

> Run di salah satu terminal
```
source /opt/ros/humble/setup.bash
ros2 run demo_nodes_cpp talker
```

> Run di terminal satunya
```
source /opt/ros/humble/setup.bash
ros2 run demo_nodes_py listener
```
