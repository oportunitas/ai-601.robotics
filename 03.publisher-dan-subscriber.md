# ROS2 Humble: Publisher dan Subscriber

Dalam ROS2, pertukaran informasi `real-time` antar proses (node) adalah hal krusial. Dua mekanisme utama untuk ini adalah `publisher` dan `subscriber`.

- **Publisher:** Bertugas mengirimkan data ke sebuah `topik`. Anggap saja seperti menyiarkan informasi ke sebuah saluran.
- **Subscriber:** Bertugas mendengarkan `topik` tertentu dan menerima data yang dikirimkan oleh publisher.

> **Catatan:** Nama ROS2 merujuk pada versi kedua dari Robot Operating System. ROS1 sudah tidak digunakan lagi karena ROS2 menawarkan kemudahan dan fleksibilitas yang lebih baik.

## Konsep Dasar

Untuk memahami cara kerja publisher dan subscriber, penting untuk mengetahui beberapa istilah kunci:

- **Node:** Sebuah program independen yang menjalankan tugas spesifik dalam sistem ROS2. Node berkomunikasi satu sama lain.
- **Topik (Topics):** Jalur komunikasi bernama tempat pesan dikirim dan diterima. Publisher mempublikasikan ke topik, dan subscriber berlangganan topik tersebut.
- **Pesan (Messages):** Struktur data yang digunakan untuk bertukar informasi antar node. ROS2 menyediakan berbagai tipe pesan standar (misalnya, `std_msgs/String` untuk teks, `geometry_msgs/Twist` untuk gerakan robot), dan tipe pesan kustom juga dapat didefinisikan.

## Membuat Publisher

Node publisher bertanggung jawab untuk mengirimkan pesan. Berikut adalah contoh dasar publisher menggunakan Python:

```python
import rclpy
from rclpy.node import Node
from std_msgs.msg import String

class MinimalPublisher(Node):

    def __init__(self):
        # Inisialisasi node dengan nama 'minimal_publisher'
        super().__init__('minimal_publisher')

        # Membuat publisher yang akan mengirim pesan tipe String ke topik bernama 'topic'
        self.publisher_ = self.create_publisher(String, 'topic')

        # Menjadwalkan callback untuk dipanggil setiap 0.5 detik
        timer_period = 0.5  # detik
        self.timer = self.create_timer(timer_period, self.timer_callback)

        self.i = 0 # Counter untuk variasi pesan

    def timer_callback(self):
        # Fungsi ini dipanggil secara periodik oleh timer
        msg = String() # Membuat instance pesan String
        msg.data = f'Halo Dunia: {self.i}' # Mengisi data pesan

        self.publisher_.publish(msg) # Mengirim pesan
        self.get_logger().info(f'Mempublikasikan: "{msg.data}"') # Mencatat pesan yang dikirim
        self.i += 1 # Menambah counter

def main(args=None):
    # Fungsi utama untuk menginisialisasi dan menjalankan node
    rclpy.init(args=args) # Inisialisasi ROS2
    minimal_publisher = MinimalPublisher() # Membuat instance node publisher
    rclpy.spin(minimal_publisher) # Menjaga node tetap berjalan

    # Membersihkan sumber daya saat node dihentikan
    minimal_publisher.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```

**Penjelasan Kode Publisher:**

1.  Impor pustaka `rclpy` dan kelas `Node`.
2.  Impor tipe pesan `String` dari `std_msgs.msg`.
3.  Definisikan kelas `MinimalPublisher` yang mewarisi dari `Node`.
4.  Di `__init__`, node diinisialisasi, dan `create_publisher` digunakan untuk menyiapkan pengiriman pesan `String` ke topik `topic`.
5.  `create_timer` menjadwalkan `timer_callback` untuk dieksekusi secara berkala.
6.  `timer_callback` membuat pesan, mengisi datanya, dan mempublikasikannya.
7.  Fungsi `main` menangani inisialisasi ROS2, pembuatan node, dan siklus hidup node.

## Membuat Subscriber

Node subscriber mendengarkan topik dan memproses pesan yang diterima. Berikut adalah contoh dasar subscriber menggunakan Python:

```python
import rclpy
from rclpy.node import Node
from std_msgs.msg import String

class MinimalSubscriber(Node):

    def __init__(self):
        # Inisialisasi node dengan nama 'minimal_subscriber'
        super().__init__('minimal_subscriber')

        # Membuat subscription untuk mendengarkan topik 'topic' dengan pesan tipe String
        # Fungsi listener_callback akan dipanggil setiap kali pesan diterima
        self.subscription = self.create_subscription(
            String,
            'topic',
            self.listener_callback,
            10) # Parameter QoS depth
        self.subscription  # Mencegah peringatan variabel tidak terpakai

    def listener_callback(self, msg):
        # Fungsi ini dieksekusi saat pesan baru diterima
        self.get_logger().info(f'Saya mendengar: "{msg.data}"') # Menampilkan data pesan

def main(args=None):
    # Fungsi utama untuk menginisialisasi dan menjalankan node
    rclpy.init(args=args) # Inisialisasi ROS2
    minimal_subscriber = MinimalSubscriber() # Membuat instance node subscriber
    rclpy.spin(minimal_subscriber) # Menjaga node tetap berjalan

    # Membersihkan sumber daya saat node dihentikan
    minimal_subscriber.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```

**Penjelasan Kode Subscriber:**

1.  Impor pustaka yang diperlukan.
2.  Definisikan kelas `MinimalSubscriber` yang mewarisi dari `Node`.
3.  Di `__init__`, `create_subscription` digunakan untuk mendengarkan topik `topic` untuk pesan `String`.
4.  `listener_callback` ditentukan sebagai fungsi yang akan dipanggil saat pesan tiba.
5.  `listener_callback` mencatat isi pesan yang diterima.
6.  Fungsi `main` menangani inisialisasi dan siklus hidup node subscriber.

## Menjalankan Node

Untuk menjalankan kedua node ini, ikuti langkah-langkah berikut:

1.  **Pastikan ROS2 Humble terinstal dan lingkungan tersource:**
    Buka terminal dan jalankan:

    ```bash
    source /opt/ros/humble/setup.bash
    ```

    Jika menggunakan workspace ROS2 kustom, pastikan untuk juga men-source file `setup.bash` dari workspace tersebut. Contoh:

    ```bash
    # source install/setup.bash
    ```

2.  **Simpan kode:**

    - Simpan kode publisher ke dalam file, misalnya `minimal_publisher.py`.
    - Simpan kode subscriber ke dalam file, misalnya `minimal_subscriber.py`.
    - Kedua file ini harus berada di dalam sebuah ROS2 package. Jika belum ada, package perlu dibuat terlebih dahulu.

3.  **Jalankan node di terminal terpisah:**

    - **Terminal 1 (Jalankan Subscriber):**

      ```bash
      ros2 run nama_package_anda minimal_subscriber_node
      ```

      (Ganti `nama_package_anda` dengan nama package ROS2 yang digunakan, dan `minimal_subscriber_node` dengan nama file Python yang sesuai, misalnya `minimal_subscriber.py`).

    - **Terminal 2 (Jalankan Publisher):**
      ```bash
      source /opt/ros/humble/setup.bash # Ulangi source jika perlu
      # source install/setup.bash # Jika menggunakan workspace kustom
      ros2 run nama_package_anda minimal_publisher_node
      ```
      (Ganti `nama_package_anda` dan `minimal_publisher_node` sesuai dengan nama package dan file yang digunakan).

Setelah berhasil dijalankan, output di terminal subscriber akan menunjukkan pesan yang diterima, dan di terminal publisher akan menunjukkan pesan yang dikirim. Ini adalah demonstrasi dasar dari mekanisme publish-subscribe di ROS2.
