# ROS2 Humble: Dasar-dasar Ignition Gazebo dan Simulasi Robot

Dalam pengembangan robotika, simulasi adalah langkah krusial sebelum beralih ke hardware fisik. Ignition Gazebo adalah simulator fisika 3D yang populer dan dalam development robot dengan ROS2.

## Instalasi Ignition Gazebo dan Integrasi ROS2

```bash
sudo apt-get update
sudo apt-get install lsb-release gnupg

sudo curl https://packages.osrfoundation.org/gazebo.gpg --output /usr/share/keyrings/pkgs-osrf-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/pkgs-osrf-archive-keyring.gpg] https://packages.osrfoundation.org/gazebo/ubuntu-stable $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/gazebo-stable.list > /dev/null
sudo apt-get update
sudo apt-get install ignition-fortress
```

Integrasi dengan ROS2:

```bash
sudo apt install ros-humble-ros-gz
```

## Jalankan Gazebo dan Sambungkan ke ROS2

Buka Ignition Gazebo, select environment `Quadcopter Teleop`, lalu klik tombol run.

Jalankan command di bawah untuk menyambungkan ROS2 dengan topic `cmd_vel` simulasi.

```bash
ros2 run ros_gz_bridge parameter_bridge /X3/cmd_vel@geometry_msgs/msg/Twist@ignition.msgs.Twist
```

## Menggerakkan Quadcopter di Gazebo

Setelah menyambungkan ROS2 ke Gazebo dan topic `cmd_vel` siap, Anda dapat mengirimkan perintah untuk menggerakkan quadcopter. Pesan `geometry_msgs/msg/Twist` memiliki dua bagian utama: `linear` (gerakan translasi) dan `angular` (gerakan rotasi).

Berikut adalah beberapa contoh perintah `ros2 topic pub` untuk menggerakkan quadcopter:

**1. Gerakan Translasi (Linear Movement):**

- **Maju (sumbu X positif):**

  ```bash
  ros2 topic pub /X3/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.5, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}" -1
  ```

  Perintah ini akan mengirimkan satu pesan `Twist` untuk menggerakkan quadcopter maju dengan kecepatan 0.5 m/s. `-1` berarti hanya mengirimkan satu pesan.

- **Mundur (sumbu X negatif):**

  ```bash
  ros2 topic pub /X3/cmd_vel geometry_msgs/msg/Twist "{linear: {x: -0.5, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}" -1
  ```

- **Ke Kanan (sumbu Y positif):**

  ```bash
  ros2 topic pub /X3/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.0, y: 0.5, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}" -1
  ```

- **Ke Kiri (sumbu Y negatif):**

  ```bash
  ros2 topic pub /X3/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.0, y: -0.5, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}" -1
  ```

- **Naik (sumbu Z positif):**

  ```bash
  ros2 topic pub /X3/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.0, y: 0.0, z: 0.5}, angular: {x: 0.0, y: 0.0, z: 0.0}}" -1
  ```

- **Turun (sumbu Z negatif):**
  ```bash
  ros2 topic pub /X3/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.0, y: 0.0, z: -0.5}, angular: {x: 0.0, y: 0.0, z: 0.0}}" -1
  ```

**2. Gerakan Angular (Rotasi):**

- **Rotasi ke Kanan (sumbu Z positif):**

  ```bash
  ros2 topic pub /X3/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.0, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.5}}" -1
  ```

  Ini akan memutar quadcopter searah jarum jam (biasanya, tergantung konfigurasi frame).

- **Rotasi ke Kiri (sumbu Z negatif):**
  ```bash
  ros2 topic pub /X3/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.0, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: -0.5}}" -1
  ```

**Catatan:**

- Nilai kecepatan (misalnya `0.5`) dapat disesuaikan untuk mengontrol kecepatan gerakan.
- Untuk gerakan berkelanjutan, Anda dapat menghilangkan flag `-1` agar pesan dikirim secara periodik (sesuai dengan frekuensi publish default ROS2). Namun, untuk contoh sederhana, `-1` sudah cukup.
- Pastikan simulator Gazebo dan `parameter_bridge` sedang berjalan sebelum menjalankan perintah `ros2 topic pub`.
